# Телеграмм бот для торговли по типу Авито

---

## Идея проекта:
- Этот бот представляет собой площадку для торговли своими личными вещами, есть возможности опубликовать товары и купить
связавшись с продавцом через ссылку на профиль @x, с возможностью снять с публикации. Товары которые создаются привязываются
к вашему уникальносу id в телеграмм

## Технологии
- aiogram

## Особенности:
- Привязка к `id` телеграмма что позволяет уникализировать пользователя
- Использование технологии FSMContextб, что в свою очередь позволяет последовательно
и поэтапно обращаться к пользователю и получать от него данные, возможность вернуться к предидущему вопросу если
есть запрос к изменению ответа,
- Использование Docker для автоматической постановки на сервер измененную версию бота

## Как работает
1. Приветствие и ознакомление с правилами
2. Структура действий
    - Купить 
        - Выбрать категорию
          - Выбрать товар
            - Связаться с продавцом
    - Опубликовать
    - Мои товары
      - Просмотр товара
      - Удаление товара
      - Релактирование товара
      
    *На любом этапе можно вернуться к предидущему*

### Как запустить?
- Установка зависимостей проекта
```bash
pip install -r requirements.txt
```
- Запуск
```bash
python3 bot.py run
```

- В `.env` файл вставьте токен вашего бота(Его можно создать в @BotFather телеграмм) на примере `.env.sample` файла, после = должен быть ваш токен
